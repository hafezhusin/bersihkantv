# DO NOT DISABLE - verified on this set, 21 Oct 2026 (same findings as the Android 12 EU list):
# com.tcl.autopair   - Bluetooth remote pairing. Disable it and a remote that unpairs (battery
#   swap, reset) can never pair again.
# com.tcl.suspension  - hosts the source-menu QuickPanel. Source key (KEYCODE_TV_INPUT, 178) goes
#   TclShortCutKeyManager -> startService com.tcl.suspension/.DismissService; disabling it makes the
#   Source key silently dead ("Unable to start service ... not found"). Restore: pm enable com.tcl.suspension.
# com.tcl.interactive - provides the tcl_tias_tbrowser service com.tcl.tv binds for the source/HbbTV
#   overlay. Disabled, vendor.tcl.tvinput.extend-service spams "Passing null binder object" plus
#   com.tcl.tbrowser NullPointerException at ~10 Hz forever.
# com.tcl.ttvs        - same TIAS chain (and the teletext soft-keyboard IME). Disable breaks the
#   live-TV source overlays like the two above.
