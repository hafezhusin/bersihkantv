# TCL 55C728 (reports as "Smart TV Pro", device G05, product G05_4K_GB), Google TV 11 (SDK 30), build AR2101
# (incremental AR27), software V8-T615T03-LF1V618, security patch 2024-11-05, MediaTek mt5889, 2.8 GB RAM.
# Turkey, wired Ethernet. Same product as examples/tcl-65c735; this list started from it.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-55c728/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-55c728/debloat.txt com.google.android.apps.tv.launcherx
# Theme:   TV_HOST=<tv ip> tools/theme.sh examples/tcl-55c728   (config.json: Live TV and the remote's buttons)
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Two days of use (from 20 Oct 2026) with several reboots, not weeks. tools/check.py found no drift after them.
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / HDMI: com.tcl.tv + com.tcl.tvinput.
# Eleven preloads came disabled from the factory on this unit and are not listed: Abema, U-NEXT, Hulu JP,
# FOD, Stan, Rakuten TV, both AirPlay packages, the game bar, notes and Alexa.
#
# Kept on purpose, unlike the 65C735 list:
# - com.tcl.ttvs: on this firmware it also holds the system updater (versionUpdateApp SystemUpdateActivity),
#   so disabling it stops OTA updates. It is not quiet: it logs every remote key press for TCL's BI
#   (KeyDownBehaviorReceiver-BI in logcat) and, at every boot, turns com.tcl.usercenter and
#   com.tcl.MultiScreenInteraction_TV (T-Cast) back on, even after `pm uninstall --user 0`. Those two are
#   left out of the list for that reason.
# - com.tcl.UpdatePeripheral (remote firmware), com.tcl.suspension (source panel, Input key).
# DO NOT DISABLE (load-bearing): the same set as the 65C735 list (com.tcl.tv, com.tcl.tvinput,
# com.tcl.settings, com.tcl.system.server, com.tcl.providers.config, com.tcl.initsetup, com.tcl.autopair,
# com.tcl.tcl_bt_rcu_service, com.tcl.keyhelp, the keyboards, Play Store and Play services).
#
# Remote: with launcherx disabled the app buttons do nothing until HomeKeyService maps them (install with
# HOME_KEY_SERVICE=1, then push config.json):
# Netflix 4062, YouTube 4065, Prime Video 4099, gear 4077 (Settings), Input 178. Firmware logs each press as
# `TclPhoneWindowManager: handleKeyBeforeQueueing, key = <code>`. The TCL Channel button never reaches the
# accessibility helpers, so it cannot be mapped. After a reinstall or theme push HomeKeyService sometimes stays
# unbound; `appops set com.gathin.tvhome APP_AUTO_START allow` and switching the service off and on fixes it.
# Other notes: the TCL update screen can't be opened from the shell (it needs
# com.tcl.permission.START_CHECK_SYSTEMUPDATE); check for updates from Settings with the remote.
# ADB on 5555 comes back by itself about 30 s after a reboot. Ethernet drops for about 5 s at power-on.
# The main logcat buffer is 1 MiB, so read logs straight away.
