# AIWA AW32B4SMG, 32-inch (Changhong, board JUC7.820.0029.7270, device redwood, product ISDB92AW), Colombia
# Android TV 14 (API 34), firmware UKNV.260504.001. About 935 MB RAM (MemTotal 935352 kB).
# Same redwood board and firmware as examples/rca-ai-pont; ro.product.model reads "AI PONT SA".
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/aiwa-aw32b4smg/debloat.txt
# Dock:    TV_HOST=<tv ip> tools/theme.sh examples/aiwa-aw32b4smg
#          config.json mirrors the config.xml the test set was built with (dock YouTube, Prime Video,
#          Play Store; Settings and Live TVx hidden). It was applied by rebuilding, not with theme.sh.
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/aiwa-aw32b4smg/debloat.txt com.google.android.tvlauncher
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.tvlauncher (Android TV, not launcherx)
# Live TV / tuner: com.mediatek.wwtv.tvcenter (left enabled; the Inputs menu uses it)
#
# Tested the same day on one set, applied in three batches with a screenshot after each,
# then one reboot. Not a multi-day soak. Owner uses only streaming apps (no antenna or cable).
#
# Checked on the new home, by screenshot and by the window in front:
# - launcher/build-and-install.sh with INPUT_KEY_SERVICE=1 set com.gathin.tvhome as Home;
#   mFocusedApp is com.gathin.tvhome/.MainActivity.
# - YouTube opens and loads its start screen with AdGuard Private DNS on.
# - Waking from standby with the remote lands on the new home.
# - Private DNS dns.adguard-dns.com validates on Wi-Fi; doubleclick.net resolves to 127.0.0.1.
#
# Known quirks on this firmware:
# - USB debugging opens network ADB on port 5555, and Wireless debugging is offered as well
#   (a random port such as 37683). The stock adb binary answered "No route to host" on the
#   wireless port; port 5555 worked.
# - com.cltv.fast ("Live TVx", FAST channels) is re-enabled by the firmware at every boot.
#   Hide it in the launcher with hidden_apps (config.json below does) instead of disabling it after each boot.
# - After a full reboot the TV came up in com.mediatek.wwtv.tvcenter instead of Home. Settings has
#   no "Power on behavior" entry (checked Device Preferences > Power, Power & energy, Inputs).
#   Waking from standby goes to Home; press Home after a cold boot.
# - The saved Wi-Fi network belongs to com.google.uid.shared (uid 10044, Play services), so
#   setupwraith is left alone; disable.sh would skip it anyway if it owned the network.
# - Play Movies & TV shows as a tile in the stock launcher but is not an installed package
#   (com.google.android.videos is absent); it disappears once launcher/ replaces Home.
